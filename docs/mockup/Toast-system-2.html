Toast System 2 — มาตรฐานใหม่

การ์ดใหม่: ไอคอนในวงกลมสีพื้นอ่อน + ขอบสีตาม tone + progress bar เส้นล่าง นับถอยหลัง 6 วินาที (หยุดเมื่อ hover) · เด้งมุมขวาล่างเหมือนเดิม · รองรับ 4 สถานะ success · error · warning · info · ข้อความคือคีย์จริงในระบบ · กด ลองเด้ง เพื่อดู animation

4 สถานะ

success · error · warning · info โทนสี + ไอคอนตาม palette ของระบบ

รูปแบบเนื้อหา

หัวข้อ + คำอธิบาย · บรรทัดเดียว มี title = หัวหนา + คำอธิบายด้านล่าง · ไม่มี title = บรรทัดเดียว

แยกตามโมดูล

toast ที่ใช้งานจริงในแต่ละโมดูล transient = useToastStore · notification = NotificationToaster (คลิกทั้งใบเพื่อนำทาง)

วิธีเรียกใช้

API เดิม — ไม่ต้องเปลี่ยน store title = หัวหนา · message = คำอธิบาย 
// เรียกจากที่ไหนก็ได้ — นอก React ก็ได้ผ่าน getState()
import { useToastStore } from '@/stores/toast';
const { push } = useToastStore.getState();

// push(message, tone, title?)  —  มี title = หัวหนา + คำอธิบายด้านล่าง
push('อัปเดตสิทธิ์ให้ Kanya P. แล้ว', 'success', 'บันทึกเรียบร้อย');
push('การเชื่อมต่อขัดข้อง ลองใหม่อีกครั้ง', 'error', 'ทำรายการไม่สำเร็จ');
push('มี 8 บัญชีถือ Full access เกินจำเป็น', 'warning', 'ตรวจสอบสิทธิ์');

// ไม่ใส่ title = บรรทัดเดียว
push('คัดลอกลิงก์แล้ว', 'success');
